# Nuvio 文档

这里是 README 装不下的细节：媒体目录怎么组织、条目在网页和客户端里怎么出现、元数据与字幕怎么工作。

文档描述的是**当前分支代码的实际行为**，不是规划。如果代码和文档不一致，以代码为准，并顺手把文档改掉。

## 阅读顺序

第一次部署：

1. [配置](configuration.md) —— 端口、数据目录、ffmpeg
2. [媒体目录与显示规则](media-layout.md) —— 把文件放对位置
3. [第三方客户端](jellyfin-clients.md) —— 用现有客户端连接

之后按需查：

- 整理番剧命名 → [媒体目录与显示规则](media-layout.md) 的「剧集库」和「常见问题」
- 配 TMDb → [元数据](metadata.md)
- 配 AI → [AI](ai.md)，字幕翻译细节在 [字幕](subtitles.md)

## 约定

- 路径示例以 Linux 为准；Docker / Podman 里应填写**容器内**路径（例如 `/video`），不是宿主机路径。
- 条目名称、季名、错误信息在服务端保持英文（`Season 1`、`Specials`、`Item does not exist`），网页按当前界面语言翻译。
- 需要重启的改动会特别注明；大多数设置保存后立即生效。
