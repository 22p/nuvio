# AI

AI 是可选功能，默认关闭。Nuvio 只实现 **OpenAI 兼容的 Chat Completions 协议**，因此 OpenAI、DeepSeek、Ollama、LM Studio、vLLM 等都能接。

## 配置

设置 → 服务器 → AI 助手：

| 项 | 说明 |
| --- | --- |
| 启用 AI | 关闭时不发出任何请求 |
| API 地址 | 需要包含版本前缀，默认 `https://api.deepseek.com/v1` |
| API Key | 保存在服务器数据库的设置表里，不是加密存储 |
| 模型 | 填 Key 后点「获取模型」，从 `/models` 的返回中选择；也可以手填 |
| 字幕翻译目标语言 | 默认 `zh-CN` |

常见端点：

```
DeepSeek     https://api.deepseek.com/v1
Ollama       http://127.0.0.1:11434/v1
LM Studio    http://127.0.0.1:1234/v1
vLLM         http://127.0.0.1:8000/v1
```

本地端点通常不需要真实 Key，但当前实现要求 Key 非空才会启用；随便填一个非空值即可。

保存后不需要重启。修改 AI 设置不会触发媒体扫描。

## 三项能力

### 1. 元数据识别

位置：设置 → 元数据匹配 →「AI 识别」。

- 取出最多 10 个没有 TMDb ID 的电影/剧集（最多可请求 25 个）
- 把文件名、目录名和当前标题交给模型，要求返回 `{"title": "...", "year": 1999}`
- 用建议标题搜索 TMDb，校验类型与年份
- 命中后写入 TMDb ID 并抓取元数据，效果与手动匹配相同

前提：必须配置 TMDb API Key。AI 只负责「猜标题」，条目数据来自 TMDb。

### 2. 字幕翻译

位置：播放器 → 字幕菜单 →「用 AI 翻译字幕」。

仅管理员可见。完整行为、发送格式、缓存位置和限制见 [字幕](subtitles.md#ai-翻译)。

要点：

- 只发送字幕文本，不发送视频
- 整条字幕一次请求，超时 5 分钟
- 时间码使用原始值，模型返回的时间不被信任
- 结果按条目缓存，翻译一次后长期可用

### 3. 主题片单

位置：设置 → AI 助手 →「生成片单」。

- 从片库取最多 80 个电影/剧集，发送名称、年份、类型、类型标签、简介摘要（截断到 120 字）
- 要求模型分成 4 组、每组 6–8 个，返回 `{"lists":[{"title":"...","ids":["..."]}]}`
- 服务端校验每个 ID 都来自输入，少于 2 个条目的列表会被丢弃
- 结果保存在服务器设置里，首页在「最近添加」下方按行渲染
- 再次生成会**覆盖**旧列表，不是追加
- 片库少于 6 个电影/剧集时拒绝生成

这是 Web 首页的自定义行，不是 Jellyfin 的 BoxSet 合集；第三方客户端的「合集」页仍然是空的。

## 请求行为

| 场景 | 超时 | 思考模式 | 输出预算 |
| --- | --- | --- | --- |
| 元数据识别 | 90 秒 | 模型默认 | 未设置 |
| 主题片单 | 90 秒 | 模型默认 | 未设置 |
| 字幕翻译 | 5 分钟 | 显式关闭（DeepSeek 的 `thinking`） | 按条数估算，上限 16000 |

兼容性处理：

- 请求可带 `response_format: {"type":"json_object"}` 或 `thinking: {"type":"disabled"}`
- 端点返回 400 时会去掉这些可选字段重试一次，所以不支持它们的服务也能用
- 字幕翻译不使用 JSON 模式，返回的是逐行文本

## 隐私

发送到模型服务的内容：

- 元数据识别：文件名、目录名、当前库内标题
- 字幕翻译：清理后的字幕文本（标签、定位、换行已去掉；外挂 ASS 还会去掉字幕组署名、卡拉 OK 碎片和绘图）。位置和时间不会发给模型，由服务端在译文轨道里保留
- 主题片单：条目名称、年份、类型、类型标签、简介摘要

不会发送：视频、音频、图片、用户密码、观看历史、其他用户信息。

使用云端服务时，字幕和片库信息会离开你的服务器；在意这一点就用 Ollama 等本地模型。

## 失败与排查

| 提示 | 原因 |
| --- | --- |
| `AI is not configured` | 开关没开、Key 为空，或设置没保存 |
| `AI model is not selected` | 模型为空 |
| `AI request failed: ...` | 端点返回非 2xx；检查地址是否包含 `/v1`、Key 是否有效、余额/限流 |
| `AI model list failed: ...` | `/models` 不可用；有些服务不实现这个接口，直接手填模型名 |
| `translation reply was not in the expected format` | 模型没有按 `序号|开始|结束|文本` 返回；换模型或降低输出长度 |
| `translation failed: context deadline exceeded` | 超时；换更快的模型，或确认端点没有把请求排队 |

字幕翻译不需要推理能力，通常用普通对话模型即可；开启思考只会让单次请求更慢。
