# 字幕

Nuvio 支持外挂字幕和内嵌字幕。网页播放器统一按 WebVTT 渲染；支持 ASS 的客户端会拿到原始 ASS 文件。

## 外挂字幕

支持的扩展名：`.srt`、`.vtt`、`.ass`、`.ssa`。

文件名必须与视频同名，或以其为前缀：

```
Severance S01E01.mkv
Severance S01E01.srt          ✅
Severance S01E01.zh-CN.srt    ✅
Severance S01E01.en.forced.srt ✅
Other Name.zh.srt             ❌ 不会关联
```

语言从视频名之后的后缀识别：

```
.zh.srt          zh
.zh-CN.srt       zh-CN
.zh-Hans.srt     zh-Hans（显示为 Chinese (Simplified)）
.zh-Hant.srt     zh-Hant（显示为 Chinese (Traditional)）
.chs.srt         zh-CN
.cht.srt         zh-TW
.en.srt          en
.en.forced.srt   en，并标记为 Forced
.ja.srt          ja
```

也接受 ISO 639-2 代码（`chi`、`eng`、`jpn`、`kor`、`fre`、`ger`……）。没有语言后缀时，会读取文件开头的内容判断：假名 → 日语，谚文 → 韩语，汉字 → 中文。文本量太少时保持 `und`。

同一个视频有多条字幕时：

- 按语言、再按路径排序
- 排序后的第一条是默认轨道
- `forced` 会出现在轨道标题里

已知限制：`.sc` / `.tc` 不在语言别名表里，简体/繁体后缀会被当成 `und`，再靠内容判断成同一个 `zh`，菜单里两条轨道都显示为「Chinese」。需要区分时请用 `.chs` / `.cht` 或 `.zh-CN` / `.zh-TW`。

## 网页播放与 ASS

- SRT / VTT 在服务端转换为 WebVTT。
- 外挂 ASS / SSA 会同时以原格式提供：网页请求 `.vtt`，支持 libass 的客户端请求 `.ass`，排版和特效保留。
- 转换时保留 WebVTT 能表达的定位与对齐；`\p1` 矢量绘图无法表示，会被丢弃。
- 网页播放器把 VTT 的位置百分比映射到**视频画面区域**，不包含黑边，因此不同宽高比和全屏状态下位置不会漂移。
- 外挂 ASS 的转换会丢弃字幕组署名（`Staff`）、卡拉 OK 逐字碎片和 `\p1` 矢量绘图。屏幕字（`Title`、`Sign` 和可读的 typesetting 文本）会保留为带位置的 cue；字体、颜色、描边等样式仍无法表达。
- 完整的歌词行（例如带 `\k` 但时长正常的 OP/ED）会保留。

播放器里的字幕设置：

- 开 / 关、切换轨道
- 字号、颜色、背景、描边
- 时间轴微调，步长 0.1 秒，按条目记忆
- 显示模式、首选语言、字号、颜色、背景、描边是全局偏好，保存在浏览器本地；时间轴偏移按条目单独保存

## 内嵌字幕

内嵌文本字幕（SubRip、ASS/SSA、WebVTT 等）通过 ffmpeg 直接提取为 WebVTT：

- 提取结果缓存在 `data/subtitles/<条目ID>-<流序号>.vtt`
- 删除缓存文件后，下次播放会重新提取
- 内嵌 ASS 在提取时已经没有样式名，无法区分字幕组署名、屏幕字和特效；这些内容都可能出现在网页字幕里。翻译时同样没有样式名可判断，只能靠「时长极短且只有一个字」的规则挡掉一部分单字碎片。

位图字幕（PGS、VobSub、DVD SUB）没有 OCR，网页端无法显示；支持这些格式的桌面客户端可以直接播放内嵌轨。Nuvio 不做图形字幕转文本。

## AI 翻译

前提：设置 → 服务器 → AI 助手已启用并填好 Key，且当前账号是管理员。

操作：播放器 → 字幕菜单 → 选中一条字幕后点「用 AI 翻译字幕」。

行为：

- 整条字幕**一次请求**发送，不再按固定条数分批；如果回复解析失败或缺少尾部条目，会自动缩小范围补发，而不是整次失败
- 发送前在本地压缩成一行一条：

  ```
  1|321.2|323.5|Hello, how are you?
  2|324.0|325.8|I'm fine, thank you.
  ```

- 本地先去掉所有标签、定位、换行、实体；外挂 ASS 还会去掉字幕组署名、卡拉 OK 碎片和绘图。内嵌字幕没有样式信息，署名和屏幕字可能仍会发送。多行合并为一行；文本里的 `|` 换成全角 `｜`
- 只采用模型返回的**文本**，时间码和 cue 设置使用原始字幕的值，所以译文不会因为模型写错时间或位置而错位
- 提示词要求不拆行、不合并；模型仍然拆行时，解析端会把续行接回上一条
- 输出是 WebVTT，保留原始 cue ID、`line` / `position` / `align` / `line-align` / `region` 等设置，以及文件头的 `STYLE` / `REGION` 块；文本里的 `&`、`<`、`>` 会转义
- 结果缓存在：

  ```
  data/subtitles/<条目ID>-<源字幕序号>.<目标语言>.vtt
  ```

- 翻译完成后，该轨道会立即加入菜单并选中；之后 `PlaybackInfo` 会一直返回它，索引从 `9000` 开始，标题为「语言 (AI)」。播放时直接读取缓存文件
- 再次点击「用 AI 翻译字幕」会重新请求并覆盖同一份缓存；想重新翻译就再点一次，想清掉就删除对应文件
- 任何一步失败（超时、限流、返回格式错误）都不会留下半成品缓存

目标语言在设置页配置，默认 `zh-CN`。字幕翻译请求：

- 超时 5 分钟（其他 AI 调用是 90 秒）
- 输出预算按条数估算，上限 16000
- 若模型支持 DeepSeek 的 `thinking` 字段，会显式关闭思考；端点不认这个字段时自动去掉重试

耗时取决于模型和网络。24 分钟番剧通常一次请求；两小时电影可能因输出上限被自动拆成两次。

## AI 翻译的限制

- 只翻译**文本字幕**；PGS 等位图字幕没有可提取的文本
- 仍需要一条已有字幕作为源；没有字幕的视频不会自动语音识别
- 译文保留原字幕的时间码和位置（`line` / `position` / `align` 等 cue 设置），但颜色、字体、描边和特效不会保留；这些信息在 ASS 转 WebVTT 时已经丢失
- 普通用户看不到翻译按钮，即使 AI 已启用
- 已经生成的字幕轨对所有能看到该条目的用户可见（轨道本身不按用户隔离）

## 常见问题

**字幕不显示**

确认文件名以视频名为前缀（`Show S01E01.zh.srt`），扩展名在支持列表里，并且重新扫描过。网页端只渲染文本字幕；位图字幕不会出现。

**两条中文字幕分不清简繁**

用 `.chs` / `.cht` 或 `.zh-CN` / `.zh-TW`；`.sc` / `.tc` 目前识别不出区别。

**ASS 特效没了**

网页端无法渲染 ASS 特效，这是 WebVTT 的能力限制。用 MPV 等支持 libass 的客户端直接播放原文件，或通过客户端请求原始 `.ass` 地址。

**翻译按钮不出现**

依次检查：AI 开关、API Key、模型、当前账号是否为管理员、是否已经选中一条字幕。

**翻译报超时**

换更快的模型或端点。字幕翻译不需要推理能力，通常用普通对话模型即可；关闭思考已由请求自动处理。
