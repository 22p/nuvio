# 配置

## 启动方式

```bash
./nuvio                                   # http://localhost:8096，数据写入 ./data
./nuvio -addr :8097 -data /srv/nuvio      # 改端口和数据目录
./nuvio -demo=false                       # 首次初始化不创建演示库
```

环境变量与命令行参数一一对应，命令行优先：

| 环境变量 | 参数 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `NUVIO_ADDR` | `-addr` | `:8096` | HTTP 监听地址 |
| `NUVIO_DATA` | `-data` | `./data` | 数据目录 |
| `NUVIO_DEMO` | `-demo` | `1` | 首次初始化是否加入演示库；`0` 关闭 |
| `NUVIO_FFMPEG` | `-ffmpeg` | 自动检测 | ffmpeg 路径 |
| `NUVIO_FFPROBE` | `-ffprobe` | 自动检测 | ffprobe 路径 |
| `NUVIO_TMDB_API_KEY` | — | 空 | TMDb v3 Key；也可在设置页填写 |

`NUVIO_DEMO` 只影响**首次初始化**。已经创建过管理员和数据目录时，改这个变量不会删除已有演示库。

ffmpeg 的优先级：命令行 `-ffmpeg` → 设置页保存的路径 → `NUVIO_FFMPEG` → `PATH`。

## 数据目录

```
data/
  nuvio.db                 用户、令牌、媒体库、片库索引、设置、观看进度
  nuvio.db-wal              WAL 日志（运行中）
  nuvio.db-shm              WAL 共享内存（运行中）
  demo/sample.mp4          内置演示片段（仅在演示库启用时）
  metadata/
    movies/                TMDb 电影图片缓存
    tvshows/               TMDb 剧集 / 季 / 单集图片缓存
    people/                人物头像缓存
  subtitles/               提取的内嵌字幕与 AI 翻译结果
  transcode/               HLS 转码 / 转封装会话
```

说明：

- SQLite 使用 WAL 模式；备份时应同时处理 `-wal` / `-shm`，或先停服务。
- `metadata/` 里是 TMDb 图片的 URL 哈希，删掉后下次请求会重新下载。
- `subtitles/` 里的内嵌字幕缓存删除后下次播放会重新提取；AI 翻译缓存删除后需要重新翻译。
- `transcode/` 在服务启动时会被清空，可以放心整体删除。

## 设置页

### 普通用户

| 区块 | 内容 |
| --- | --- |
| 界面语言 | English / 简体中文 / 繁體中文 / 日本語 / 한국어 |
| 播放 | 码率上限、优先直连、首选音轨语言、自动播放下一集 |
| 字幕 | 显示模式（关闭 / 自动 / 始终）、首选语言、字号、颜色、背景透明度、描边 |
| 账户 | 修改密码 |
| 登录设备 | 当前账号的令牌、设备名、客户端、IP、最近活跃时间；可撤销其他设备 |
| 关于 | 版本与项目信息 |

### 管理员

| 区块 | 内容 |
| --- | --- |
| 媒体库 | 添加/删除媒体库、路径、类型；扫描状态与「立即扫描」 |
| 转码 | 开关转码/转封装、硬件加速、输出编码、默认码率、预设、ffmpeg/ffprobe 路径、服务器名称 |
| 元数据 | TMDb API Key、元数据语言 |
| AI 助手 | 启用、地址、Key、模型（可从 `/models` 获取）、翻译目标语言、生成主题片单 |
| 元数据匹配 | 未匹配条目列表、搜索、手动匹配、AI 识别 |

用户与权限在独立的 `/users` 页面管理，不在设置页。

## 媒体库

- 类型：电影（`movies`）、剧集（`tvshows`）、混合（`mixed`）
- 一个库可以配置多个路径
- 路径必须是服务器上存在的**绝对路径**
- 添加库会触发扫描；之后需要手动扫描才能看到新增或改名的文件
- 普通扫描会遍历整个目录，但对大小和修改时间都没变的文件跳过 ffprobe，复用上次的探测结果
- 「全量扫描」会重新探测所有文件，适合更换 ffprobe 或技术信息异常时使用
- 删除库只移除索引，不删除媒体文件

目录结构对识别结果的影响很大，见 [媒体目录与显示规则](media-layout.md)。

## 账号与权限

每个账号可以设置：

- 可见媒体库（不勾选则完全看不到该库的条目）
- 允许转码
- 允许转封装
- 管理员标记

关闭转码/转封装后，服务器不会为该账号启动对应的 ffmpeg 任务；客户端仍可能直连原文件。

密码使用 PBKDF2-HMAC-SHA256（210,000 次迭代）加盐哈希。令牌是持久化的，撤销后该设备需要重新登录。

## 备份与迁移

1. 停止服务
2. 复制整个数据目录（至少包含 `nuvio.db`）
3. 新机器上恢复目录，用相同的 `-data` 路径启动

数据目录里有：

- 用户密码哈希与访问令牌
- TMDb / AI 的 API Key（**明文**保存在设置中）
- 媒体库路径与扫描索引
- 每个用户的观看进度、收藏

媒体文件不在数据目录里，需要单独迁移，并在新机器上确认库路径仍然存在。

## 反向代理

Nuvio 只提供 HTTP。公网访问建议放在 Caddy / Nginx 后启用 HTTPS：

- 需要转发 `Authorization`、`X-Emby-Token`、`X-Emby-Authorization` 头
- HLS 分片是普通 GET 请求，不要缓存或缓冲
- `/Videos/{id}/stream` 支持 Range，代理必须保留 `Range` 请求头并返回 `206`
- 不要给 `/Videos/...` 加额外鉴权，否则第三方客户端会把 URL 直接交给播放器时失败（见 [第三方客户端](jellyfin-clients.md)）

## 日志

- 扫描、ffmpeg 错误、图片下载失败会打印到标准输出
- Docker / Podman 用 `docker logs` / `journalctl --user -u nuvio` 查看
- 扫描错误也会显示在设置页的媒体库区块
